
We want to make a web artifact for a demo of 
grid paint / vector field painting and it can use attractors.
It uses what is called a key-click which means that 
the mouse moves the cursor but various keys act as 
different clicks (functions).  So the user might 
move the cursor that is represented by a circle 
and the [ and ] keys will decrease and increase the size of the circle,  the F key will deposit or act on the grid nodes as previewed by the hover.  It allows assigning a variety of key-clicks to the keyboard to control the drawing and the app too.
